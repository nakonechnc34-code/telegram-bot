# Soft Blue — ручная приёмка перед слиянием

Автоматические структурные тесты **не** подтверждают работу интерфейса в браузере. Проверять на тестовом стенде, с тестовыми учётными записями и данными. Не использовать реальные медицинские сведения в тестовых скриншотах или логах.

## Доступ и сессии
- [ ] Вход с корректным логином и паролем; отказ при ошибочных данных.
- [ ] Выход завершает сессию; после выхода защищённые данные не отображаются.
- [ ] Обновление страницы с действующей и недействительной сессией.
- [ ] Суперадминистратор, HR и ограниченный администратор: видимость пунктов, доступ к действиям и отказ на сервере для запрещённых операций.
- [ ] Проверка, что чужие медицинские документы недоступны через прямой API-запрос.

## Навигация
- [ ] Все 14 разделов открываются; активный пункт подсвечен.
- [ ] Счётчики новостей, стандартов и вопросов соответствуют данным.
- [ ] Мобильное меню открывается и закрывается; нет перекрытых кнопок.
- [ ] Клавиатура: Tab, Enter, Escape (где предусмотрен), видимый фокус.

## Сотрудники
- [ ] Поиск по ФИО и логину, переключение активные/уволенные.
- [ ] Добавление и редактирование сотрудника, сохранение и повторное открытие.
- [ ] Увольнение и восстановление, подтверждение и обновление списка.
- [ ] Отсутствие кнопок редактирования/увольнения без соответствующих прав.

## Медкнижки
- [ ] Вкладки сотрудники/врачи/анализы/прививки.
- [ ] Три статуса: действительна/истекает/недействительна.
- [ ] Редактирование разрешённой записи и запрет для роли без прав.
- [ ] Добавление и изменение справочников врачей, анализов, прививок.
- [ ] Проверка, что отображаемые данные принадлежат разрешённому сотруднику.

## Остальные разделы
- [ ] Новости: просмотр, создание/модерация по роли.
- [ ] Стандарты: просмотр и действия по роли.
- [ ] Сертификация, FAQ, рестораны, должности, гражданства.
- [ ] Вопросы: просмотр и ответ.
- [ ] Администраторы: управление только для разрешённых ролей.
- [ ] Отчёты и история: открытие, фильтры и корректное отображение.

## Устройства и качество
- [ ] Desktop 1440px, laptop 1024px, mobile 390px и 320px.
- [ ] Таблицы прокручиваются горизонтально, данные и кнопки не обрезаются.
- [ ] Модальные окна и формы доступны, ошибки валидации видны.
- [ ] В консоли браузера нет ошибок JS, в сети нет неожиданных 4xx/5xx.
- [ ] До/после: функциональное поведение совпадает с текущей рабочей версией.

**Правило выпуска:** при любой регрессии функциональности или прав доступа PR не сливать. Цепочка PR #5 → #6 → #7 → #8 → PR проверки должна быть рассмотрена в правильном порядке.
