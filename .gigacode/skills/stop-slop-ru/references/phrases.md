# Фразы и слова на удаление

## Вводный мусор

Убрать, начать сразу с сути.

- «Давайте разберемся...»
- «Давайте рассмотрим...»
- «Давайте поговорим о...»
- «Хороший вопрос!» / «Отличный вопрос!»
- «Рад, что вы спросили»
- «Конечно!» / «Разумеется!» / «Безусловно!» (в начале ответа)
- «Понял вас!» / «Принято!»
- «Вот что вам нужно знать:»
- «Позвольте объяснить:»
- «Вот в чем дело:»
- «На самом деле дело вот в чем:»
- «Важно понять, что...»
- «Стоит отметить, что...»
- «Следует сказать, что...»
- «Необходимо подчеркнуть, что...»
- «Если разобраться,...»

Любая конструкция «вот что / вот в чем» - это разбег перед мыслью. Вырезать и сказать мысль сразу.

## Усилители без смысла

Ничего не добавляют - вырезать.

- «по-настоящему» (в значении «really»)
- «действительно» (как усилитель, не как слово «на деле»)
- «просто» (как усилитель)
- «буквально» (как усилитель, не в прямом значении)
- «именно» (как усилитель)
- «конкретно» (как пустой усилитель)
- «в целом» (без конкретного противопоставления части)
- «по сути» (как вводное слово без функции)
- «в принципе» (как пустой вводный оборот)
- «так сказать»
- «своего рода»
- «глубоко», «подлинно», «фундаментально», «неотъемлемо», «неизбежно», «принципиально»
- «на самом деле» (как тик, не как смысловое уточнение)

Также вырезать: «в сегодняшнем мире...», «стоит отметить, что», «в конечном счете», «когда речь заходит о», «в мире, где», «реальность такова, что».

## Деловые клише

| Избегать | Использовать |
|----------|--------------|
| оптимизировать процессы | улучшить / ускорить / упростить работу |
| повысить эффективность | сделать быстрее / дешевле / точнее |
| обеспечить синергию | работать согласованно |
| двигаться вперед | следующий шаг - [конкретное действие] |
| выйти на новый уровень | [назвать конкретный результат] |
| комплексный подход | [описать, что именно делается] |
| в рамках данного проекта | в этом проекте |
| на текущем этапе | сейчас |
| принять во внимание | учесть |
| нести ответственность | отвечать за [что конкретно] |
| навигировать вызовы (navigate challenges) | справляться с [чем конкретно] |
| глубокое погружение (deep dive) | разбор, анализ |

## Ленивые крайности

Ложная авторитетность без опоры на данные - убрать или заменить конкретикой.

- «каждый», «всегда», «никогда», «все», «никто», «любой»

Пример: «Каждая команда сталкивается с этим» → «Три из пяти команд в опросе столкнулись с этим» (или назвать источник).

## Ложные противопоставления

Не через отрицание - прямо.

| Избегать | Делать |
|----------|--------|
| «Это не провал, а опыт» | «Это опыт» |
| «Не потому что X, а потому что Y» | «Потому что Y» |
| «Вопрос не в X, а в Y» | «Вопрос в Y» |
| «Дело не в X. Дело в Y.» | «Дело в Y» |
| «Это не X, это Y» | «Это Y» |
| «Не просто X, но и Y» | «X и Y» |

## Туманные декларации

Объявляют о важности, не называя ее - переписать.

- «Это имеет большое значение» → назвать, что именно меняется
- «Ситуация неоднозначная» → сказать, в чем конкретно
- «Последствия серьезны» → назвать конкретные последствия
- «Причины структурные» → назвать конкретные причины
- «Это глубокая проблема» → описать саму проблему

## Ложная агентность неодушевленных предметов

Называть человека, не вещь.

| Избегать | Делать |
|----------|--------|
| «Решение приняло форму...» | «Команда решила...» |
| «Данные говорят нам» | «Из данных следует / аналитик прочитал» |
| «Рынок вознаграждает» | «Покупатели платят за...» |
| «Разговор сдвинулся в сторону» | «[Кто-то] направил разговор к...» |
| «Культура меняется» | «Люди начали вести себя иначе» |
| «Задача решается» | «[Кто] решает задачу» |

## Нарратор-с-балкона

Ставить читателя внутрь, не описывать со стороны.

| Избегать | Делать |
|----------|--------|
| «Люди склонны...» | «Вы, скорее всего,...» |
| «Никто специально не задумывал...» | «Вы не садились однажды и не решали...» |
| «Так устроено потому, что...» | «Это работает так, потому что вы / мы...» |

## Мета-комментарии к тексту

Текст должен двигаться, не объявлять о себе.

- «В этом ответе я расскажу о...»
- «В следующем разделе мы рассмотрим...»
- «Как мы увидим далее...»
- «Подведем итог...» (если итог не нужен)
- «Обобщая вышесказанное...»
- «Таким образом, мы видим, что...»

## Риторические заходы

Вывод - не анонс вывода.

- «А теперь подумайте:» → сразу мысль
- «Что если?..» (как риторический прием) → сформулировать прямо
- «Интересно, правда?» → убрать
- «Звучит знакомо?» → убрать
- «И это только начало» → убрать или назвать, что будет дальше
