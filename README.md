# Wokker Bot — Telegram‑бот для сотрудников сети ресторанов

Бот для внутренней коммуникации и доступа к информации о ресторанах сети Wokker. Включает регистрацию сотрудников, справочник точек, админ‑панель и Web App.

## Функционал

- **Регистрация сотрудника**: ФИО, телефон, дата рождения, должность, ресторан.
- **Справочник ресторанов**: адреса, часы работы, телефоны, ссылка на Яндекс Карты.
- **Админ‑панель**: список пользователей, блокировка/разблокировка, удаление, статистика по должностям и ресторанам.
- **Web App**: просмотр списка ресторанов в интерфейсе Telegram.
