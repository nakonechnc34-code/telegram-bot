# Stop Slop RU

Скилл для устранения ИИ-штампов и типографских ошибок в русском тексте.

## Что это

Риторика - ложные противопоставления, драматичная фрагментация, ритм, деятель вместо неодушевленного агента - основана на **stop-slop** (Hardik Pandya, MIT License). Типографика - буква «ё», правила тире, перевод англицизмов - собственная разработка.

Плюс раздел, которого не было ни в одном из исходников: ленивые крайности («каждый», «всегда», «никогда»).

## Структура

```
stop-slop-ru/
├── SKILL.md              # основные правила и директива "ответ на русском"
├── references/
│   ├── phrases.md         # фразы и слова на удаление
│   ├── structures.md      # структурные и ритмические паттерны
│   ├── anglicisms.md      # таблица замен англицизмов
│   └── examples.md        # примеры до/после
├── REPORT.md              # результаты проверки по чек-листу ТЗ
└── LICENSE                # MIT (наследована от stop-slop, атрибуция сохранена)
```

## Отличия от оригинального stop-slop

- Удалена ссылка на сайт автора из метаданных (FR-1/FR-2, запрет внешних URL).
- Добавлена директива обязательного ответа на русском языке (FR-3).
- Правила «нет наречиям» и «нет длинному тире» заменены на правила, специфичные для русской грамматики (усилители, тире по правилу нейтрального употребления).
- Добавлен раздел «ленивые крайности», которого не было в исходном stop-slop.
- Таблицы деловых клише и англицизмов дополнены русскими эквивалентами.
